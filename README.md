# ER Productivity Nan Connector

ตัวติดตั้ง ER Productivity Connector สำหรับโรงพยาบาลในจังหวัดน่าน

ดาวน์โหลดตัวติดตั้งรุ่นล่าสุดจากหน้า [Releases](https://github.com/kritanaiyo591-hub/er-productivity-nan-connector/releases/latest)

รุ่น 0.9.3 ส่งชื่อเครื่องและเวอร์ชัน Agent พร้อมยอดผู้ป่วย ER เพื่อให้ผู้ดูแลตรวจสอบในประวัติการบันทึกข้อมูลของระบบกลางได้ และรายงานช่วงนาทีที่ตั้งไว้ผ่าน heartbeat

ตั้งแต่รุ่น 0.9.3 เมื่อกด **ตรวจสอบเวอร์ชัน** และยืนยันติดตั้งรุ่นใหม่ โปรแกรมจะดาวน์โหลด ตรวจ SHA-256 ติดตั้ง แล้วเปิดหน้าต่างรุ่นใหม่อัตโนมัติ โดยคงการตั้งค่าเดิมไว้ ส่วนอัปเดตอัตโนมัติในรอบส่งข้อมูลจะทำงานเงียบ ๆ ไม่เปิดหน้าต่าง

การอัปเดตครั้งแรกจากรุ่น 0.9.2 หรือต่ำกว่ายังใช้ตัวอัปเดตรุ่นเดิม จึงต้องเปิดโปรแกรมเองหนึ่งครั้งหลังติดตั้ง 0.9.3
